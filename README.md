# 올리브짬뽕 할로윈 게임

간석동 **올리브짬뽕중식당** 10월 매장용 미니게임 앱 (설치형 웹앱 / PWA)

- **짬뽕 타로**: 갑오징어 카드 5장 중 1장 → 오늘의 운세 + 추천 메뉴
- **메뉴판 맞추기**: 메뉴 ↔ 가격 짝맞추기, 기록 저장
- 배경음악·효과음 내장 (외부 음원 없음, 저작권 걱정 없음)
- "리뷰 쓰면 음료수 공짜" 버튼 → 네이버 플레이스 https://naver.me/51upL4Az
- 폰 홈 화면에 앱처럼 설치 가능, 한 번 열면 오프라인에서도 동작

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 게임 본체 (이거 하나로 다 돌아감) |
| `manifest.webmanifest` | 앱 이름·아이콘·색 (홈 화면 설치용) |
| `sw.js` | 오프라인 캐시 |
| `og.png` | 카톡·문자 링크 공유 시 뜨는 가로 썸네일 (1200×600) |
| `icons/` | 앱 아이콘, 카톡 프사(`profile.png`) |
| `.nojekyll` | GitHub Pages 설정용 빈 파일 (지우지 말 것) |

## GitHub에 올리기 (10분)

1. GitHub에서 **New repository** → 이름 `olivejjamppong` → **Public** → Create
2. **Add file → Upload files** → 이 폴더 안의 파일·폴더 전부 드래그 → Commit
3. **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
4. 1~2분 뒤 주소: **https://eyecoler.github.io/olivejjamppong/**

> 카톡 썸네일 주소는 위 주소로 설정 완료. 저장소 이름을 바꾸면 `index.html`의 `og:image`, `og:url` 두 줄도 같이 바꿔야 함.

## 폰에 앱으로 설치

- **안드로이드(크롬)**: 주소 열기 → 메뉴(⋮) → **홈 화면에 추가 / 앱 설치**
- **아이폰(사파리)**: 주소 열기 → 공유 버튼 → **홈 화면에 추가**

## 수정할 때

- 타로 운세·추천 메뉴: `index.html`에서 `const TAROT=` 검색
- 메뉴판 카드·가격: `const MENU=` 검색
- 수정 후 다시 업로드하면 끝. 손님 폰은 다음에 열 때 자동으로 새 버전.
  - 크게 바꿨는데 안 바뀌면 `sw.js`의 `olive-v1`을 `olive-v2`로 올리기
